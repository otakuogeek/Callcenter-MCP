# 🏥 Bienvenido al Sistema Biosanarcall

## ¿Qué es Biosanarcall?

Biosanarcall es el sistema de gestión de citas médicas de **Fundación Biosanar IPS**. Permite a pacientes, médicos y personal administrativo gestionar todo lo relacionado con las consultas médicas.

---

## 👥 ¿Quién puede usar el sistema?

| Usuario | ¿Cómo acceder? |
|---------|----------------|
| **Pacientes** | Desde la página principal del sitio web |
| **Médicos** | Portal especial para doctores |
| **Personal administrativo** | Panel de administración |
